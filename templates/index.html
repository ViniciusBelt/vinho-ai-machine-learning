Objetivo do Sistema

Este sistema utiliza um modelo de Machine Learning supervisionado treinado com dados físico-químicos reais (UCI Machine Learning Repository - Cortez et al., 2009) para estimar se um lote de vinho tinto atinge os critérios de Alta Qualidade (Vinho Premium, nota ≥ 7) ou se enquadra na categoria Padrão / Comercial (< 7). Preencha os 11 parâmetros laboratoriais abaixo ou selecione um exemplo pronto para teste rápido.
